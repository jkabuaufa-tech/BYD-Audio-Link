<b>Versi baru 2.10.20 tersedia.</b> Pembaruan 2.10.20 (kumulatif; butuh Modul server 1.10.18 untuk Release / Unrelease &amp; BASO-BASTA).
BARU 2.10.20 — KONTROL RELEASE / UNRELEASE (SOP SAP HANA) · PREVIEW PO &amp; PROGRES · BASO &amp; BASTA PER ALAT: (1) Register Kontrak berjenjang: Staf Pengadaan membuat kontrak / PO lalu menekan "Ajukan"; hanya Admin yang dapat "Release" (posting). Koreksi sesudah release hanya lewat "Unrelease" Admin beralasan min. 12 karakter — ditolak bila sudah ada BK / tagihan, penerimaan gudang aktif, atau addendum di atasnya sudah direlease. Tiap baris berlabel status SAP: Draf · Diajukan · Released · Unrelease-revisi (beserta alasannya). (2) Tombol "Preview PO" di samping chip "PO TTD": pratinjau cetak PO / kontrak dari data tersimpan (para pihak, item, WBS, nilai DPP, status release); kontrak yang belum direlease bertanda DRAF. (3) Form Input Progres: tombol "Preview" di samping tautan BAPM / BAPP — rincian volume s/d lalu, periode ini, s/d kini dan nilai per item, dengan peringatan bila kumulatif melebihi volume kontrak atau nilai hitung ulang berbeda dari nilai BK; dari jendela yang sama dapat membuka Preview BA &amp; format Excel baku. (4) Menu Gudang › "BASO &amp; BASTA Alat": Berita Acara Alat Siap Operasi + Berita Acara Serah Terima Alat, SATU berkas per unit alat (1 SPSA berisi 2 alat → 2 berkas). Tanggal otomatis = tanggal PO Sewa Alat (SPSA); Pihak Pertama Kepala Proyek, Pihak Kedua Direktur penyedia alat; isian lapangan: Merk / Type, No. Mesin, No. Rangka, Bahan Bakar, Tahun Pembuatan, No. Polisi, perlengkapan (Manual Pabrik, STNK, Kotak P3K, Kaca Spion) dan foto 3 sisi (depan, belakang, samping) sebagai lampiran. Dapat diisi Pengadaan maupun Petugas Gudang. Menu "Form Input Kontrak" &amp; "Lacak Alur" tetap dilebur di Register Kontrak (sejak 2.7.2 / 2.8.1).
